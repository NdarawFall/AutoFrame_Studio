02_Composants • Module Background

Galerie & Modèles d'Arrière-Plans

5 directions artistiques indispensables pour vos vidéos. Zéro grille répétitive : choisissez le fond adapté à votre tonalité éditoriale et copiez le CSS en un clic.

⚪ Tout Blanc
Minimal / Editorial
Clarté & Minimalisme
Idéal pour les vidéos explicatives, le style Notion ou les démonstrations épurées.
Fond 100% blanc pur. Offre un contraste optimal pour la typographie noire, les illustrations vectorielles et les mockups d'appareils.
background: #ffffff; color: #09090b;
⚫ Tout Noir
Cinématique / OLED
Contraste Absolu
Idéal pour faire ressortir les néons, les cartes Shadcn UI et le motion design intense.
Fond noir profond `#000000`. Supprime toute distraction visuelle et magnifie les couleurs vives, les badges d'accent et les textes blancs.
background: #000000; color: #ffffff;
🎨 Couleur Unique
Brand Kit / Signature
Teinte de Marque Unique
Une couleur franche et affirmée pour ancrer l'identité visuelle de votre chaîne.
Un aplat de couleur solide sur-mesure. Choisissez ci-dessous une couleur prédéfinie ou personnalisez le code hexadécimal :
Nuancier :
background: #1e3a8a; color: #ffffff;
🌈 Fond Gradient
Dynamique / Profondeur
Atmosphère & Richesse
Donne du relief et une dimension haut de gamme sans saturer la composition.
Dégradé multi-points fluide. Peut être combiné avec une légère animation de translation lente pour créer un fond subtilement vivant.
background: linear-gradient(135deg, #0f172a 0%, #1e1b4b 50%, #311042 100%); color: #ffffff;
🖼️ Image avec Flou & Scrim
Cinématique / B-Roll Backdrop
Effet Bokeh d'Arrière-Plan
Floutez n'importe quelle photo ou capture d'écran avec un voile sombre pour mettre en valeur les éléments du premier plan.
Technique éprouvée des vidéos professionnelles : une image de fond agrandie (`scale(1.15)` pour supprimer les bords flous), adoucie par un filtre Gaussian Blur (`filter: blur(28px)`) et recouverte d'un voile sombre semi-transparent (`rgba(0,0,0,0.45)`) pour garantir 100% de lisibilité textuelle.
/* HTML : <div class="bg-blur-container"><img src="..." class="bg-blur-img"><div class="bg-scrim"></div></div> */ .bg-blur-container { position: absolute; inset: 0; overflow: hidden; background: #000; } .bg-blur-img { position: absolute; inset: -20px; width: calc(100% + 40px); height: calc(100% + 40px); object-fit: cover; filter: blur(28px); transform: scale(1.15); opacity: 0.75; } .bg-scrim { position: absolute; inset: 0; background: rgba(0, 0, 0, 0.45); }
