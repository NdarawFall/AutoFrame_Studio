# Règle : Organisation des Skills et des Règles

## 1. Dossier `.agents/`
* Le dossier `.agents/` est **strictement réservé aux règles** (`.agents/rules/`).
* **Ne jamais créer de dossier `skills` dans `.agents/`**.

## 2. Dossier `00_Skills/`
* Tous les skills, guides et documentations techniques du projet doivent être placés exclusivement dans le dossier `00_Skills/`.
